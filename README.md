# Fúria Capixaba

Versão para celular (PWA) do jogo. **Jogar ou instalar:** https://brununes.github.io/furia-capixaba-jogo/

No Android, abra o endereço no Chrome e toque em "Instalar o jogo" (ou menu ⋮ → "Adicionar à tela inicial").

Aqui fica só o jogo montado; o código-fonte, o roteiro e as fotos estão no repositório privado.
